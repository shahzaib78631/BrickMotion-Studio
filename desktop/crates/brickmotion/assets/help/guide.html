BrickMotion Help

Build a model, then animate how it goes together.

BasicsBuildingAnimatingExporting

Basics

  • Open an LDraw model with ⌘O, or start a new one with ⌘N.
  • Orbit the view by right-dragging, pan with ⌥-drag or a middle-drag, and zoom with the scroll wheel. F fits the model.
  • With the Select tool, drag on empty space to select every piece inside the box; hold ⇧ to add to the selection. With Move or Rotate, a drag on empty space orbits.
  • BrickMotion has two workspaces: Build to edit the model and Animate to make its build movie.
  • Every command is in the Command Palette, ⌘K. Help › Keyboard Shortcuts lists the keys.

Building

  • Add parts from the Library; click to place them in the viewport.
  • Click selects a submodel; hold ⌥ to pick a single piece (Settings › Building swaps this).
  • Move with W, rotate with E, and nudge with the arrow keys.
  • Right-click a part for Make Submodel, Group, Move to Step and more.
  • Steps decide the order parts appear in; the Steps tab edits them.

Animating

  • BrickMotion plans a flight for each part from its step and how it connects.
  • Play with Space. The timeline shows each part's clip; drag a clip to retime it.
  • Build Settings sets the pacing; Staging sets where parts wait before they fly in.
  • Camera keys live on the camera lane; add one from the current view.

Exporting

  • File › Export Movie renders the build as a video, with an optional logo.
  • File › Export Still saves the current view as an image.
  • Exports run in the Render Queue, so you can keep working.
