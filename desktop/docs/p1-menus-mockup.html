1 · Right-click a piece

The menu acts on the piece you clicked. If that piece is already part of a selection, it acts on the whole selection. Disabled rows stay visible so the menu doesn't change shape. Every row is an existing command, so the shortcuts are the same ones the menu bar and ⌘K show.

3 · Menu bar — every command reachable

Two menus are new: Model and Steps. Each command sits in exactly one menu, and its ribbon placement doesn't change. Today 69 of 109 commands appear in no menu; afterwards every command does, apart from arrow nudges and tool keys, which live in the Edit › Nudge submenu.

4 · Naming: Make Submodel, New Submodel, Rename, Group

A small sheet over the viewport. The field starts with the next free name and is already selected. Return confirms, Esc cancels. The same sheet handles all four actions; only the title and button text change.
