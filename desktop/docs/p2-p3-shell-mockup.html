P2 · 1 — One theme, two appearances

Every colour comes from the theme, so the same screen draws in Dark and in Light. The ribbon tabs become underlined text instead of filled blue pills. Orange is used only for the playhead: the logo, the workspace button and the tree icons use the accent or neutral grey. Light uses the tokens from the M7a mockup you already approved.

P2 · 2 — Preferences (⌘,)

A standard Mac settings window: a search field and five sections on the left, grouped rows on the right. Changes apply as you make them, with no Apply/OK buttons, as in macOS System Settings. Every row is a real setting that already exists in the app, or is the new Appearance setting.

P2 · 3 — About, and Help

About replaces the stock macOS panel. It lists the app, engine and renderer versions, read from the build and from the engine; Copy puts the same lines on the clipboard for bug reports. The Help menu keeps Keyboard Shortcuts and Command Palette, and adds BrickMotion Help, which opens a short offline guide in your browser (Basics, Building, Animating, Exporting).

P3 — Depth: exact transforms, scale, the tree row menu

Properties gains a Transform section. Each number is a scrub field: drag sideways to change it (by 1 stud, or 1 plate for Y; hold ⌥ for fine steps, ⇧ for coarse), or click it to type. With several pieces selected, fields that differ show "—", and editing one moves every piece by the same amount. The Scale tool (S) adds handles to the gizmo and stretches any selection, from 0.05× to 20×, in one undo step. Scaled bricks no longer fit real parts, so it is meant for scenery and props. The other P3 items have no new screens: marquee select (drag on empty space), Select ▸ Same Part / Same Colour, and Fit Together.

Decisions for you
  1. Five text sizes (15 / 13 / 12.5 / 11.5 / 10.5) rather than the two in the old rule. Two sizes can't separate panel titles from tree counts without adding more weights.
  2. Preferences apply as you change them (macOS style), rather than with the web version's Apply/OK buttons.
  3. Home opens on launch when nothing was open last time. Preferences › General can choose "last document" instead.
  4. BrickMotion Help is a short offline guide that opens in the browser. The alternative is to leave Help as just Shortcuts and the Palette for now.
