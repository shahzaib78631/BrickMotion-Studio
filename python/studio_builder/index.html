How this build works

  1. Read step numbers, quantities and part thumbnails from page pixels.
  2. Match the thumbnails against your local LDraw library.
  3. Fit the view and place new pieces against the existing assembly.
  4. Review source / reconstruction / overlay and download the MPD.

Automatic layout currently targets numbered Studio steps with parts lists above the model view. Custom layouts can be corrected in the observations editor. Repeated callouts and ambiguous hidden geometry require review.

2. Review your reconstruction

Review required
