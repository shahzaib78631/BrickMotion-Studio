# Swift timeline inventory

This inventory compares the shipped web timeline source with the Swift editor. It covers interaction and state changes as well as visible controls.

| Surface | Web workflow | Swift status and implementation |
| --- | --- | --- |
| Build transport | Play and pause, previous and next step, Space, seek, follow playback, camera follow, zoom buttons and modifier-wheel zoom, Fit | Shared transport, rate, loop, follow, overview, pointer-anchored magnification, Fit and Director Preview exist. Verify keyboard routing and end-to-end playback. |
| Build ruler | Scrub from ruler, auto-scroll at the edge, show selected build scope and timeline end | Native ruler and overview support scrubbing and edge scrolling. The final tick reaches the trailing gutter at Fit and high zoom. Final part labels stay inside the axis with their true flight starts retained. |
| Planner | Automatic planning, stale build state, progress, error details, copy diagnostics, retry, Standard fallback, route diagnostics and jump to affected piece | Native displays the planning stage and keeps stale clips visible. Diagnostics provide copy, rebuild, a jump to flagged parts and a clearly identified Standard Preview in authored step order. |
| Step blocks | Open editor, drag to reorder whole steps, trim trailing hold from zero by dragging, arrow keys change hold, context menu for selection, show, split, gather, join, move, pin, insert, motion and delete | Native context menu, whole-step drag, and a focused edge handle adjust holds from zero to ten seconds. The secondary pause lane remains available. |
| Submodel clips | Show local build and attach time, surface nested clips, open the submodel in its own timeline | Native shows scheduled assembly and attach spans when available, and an authored submodel’s constituent arrivals otherwise. Clips open that submodel’s timeline. |
| Parts lane | Part ID and colour, group selection, frame, drag one part or a selection to any step and arrival position, insertion marker, modifier-drop to force order, individual force/release pin, group reorder feedback, catalogue drop at insertion, double click to edit flight as keys | Native shows a drop marker for cross-step and group moves, pans when dragging near a horizontal edge, supports persistent pins and Option-drop, and places catalogue parts at the marker’s authored insertion. Double-click a part to open its flight as editable keys, including nested parts. |
| Part menu | Single and multi-selection actions for frame, move to existing/new step, split or gather, arrive first/last/earlier/later, motion override and reset, delete | The native context menu acts on the current selection when opened from a selected clip. It supports grouped move, split, pin, motion, frame and delete. |
| Sequence clips | Intro, Build and Hero with mouse and keyboard trim handles | The Swift segments have keyboard and drag trim handles backed by the project’s video settings. The release suite checks exact timing, path reuse and save/reopen. |
| Motion | Project, step and part scopes, inherited and explicit timing, presets, duration, landing, hover and easing | Native Motion workspace and editors exist. Confirm multi-part edits, inheritance, marker state and keyboard access. |
| Keyframe transport | Insert selected channels, Auto Key, previous/next key, explicit frame, play/loop, zoom and Fit | Native transport, per-property controls and direct frame entry exist. Audit playback routing and key insertion shortcuts. |
| Keyframe lanes | Search and animated-only filter, object/channel disclosures, build source with start and speed, multi-select and marquee, drag retiming, key menu, visibility channels | One object opens its property lanes. A submodel’s track and a baked part inside it have independent rows, even when opening either one highlights the same part in the viewport. Selecting multiple objects opens aligned frame rows with box selection, drag retiming and delete in a single edit. Focused key grids handle playback, frame stepping, selection and Delete. The pane test confirms that editing shortcuts stay in the timeline. |
| Keyframe properties | Per-channel value edit, interpolation, location/rotation/scale values, FPS and scene range | Native property editing and scene range exist. Verify parity for all channels and authored interpolation. |
| Build-to-keys workflow | Link/unlink, bake selected, bake and detach all, rebake, use edited path in Build, return flight to planner, inspect motion warnings and jump to each contact | Native prepares selected and whole-build bakes off the main thread, then applies one undoable edit. Whole-build bake includes nested leaves and detaches the layer after all flights are represented. An individual flight can return to the planner. A local edited flight can also supply its route to Build. Motion Check lists separate sampled contact ranges for the selected part, with a jump to each range. |
